A single graph neural network dynamics model, learned from real-robot RGB-D data across nine tools and three interaction modes (grippers, rollers, presses), for deformable-object manipulation. Because the model is differentiable, it supports both tool shape optimization and multi-gripper motion planning toward a target dough shape.
